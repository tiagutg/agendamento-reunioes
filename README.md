# Sistema de Agendamento de Reuniões - AVA UniSales

Projeto acadêmico para agendamento de reuniões entre alunos, professores e coordenadores dentro de uma interface inspirada no AVA UniSales.

## Funcionalidades

- Agendar reunião
- Selecionar professor/coordenador
- Definir data e horário
- Escolher formato: presencial, online ou híbrido
- Informar tópico e resumo
- Visualizar agendamentos cadastrados
- Menu lateral recolhível

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Font Awesome
