# 📘 Documentação do Projeto — AgendeUniSales

---

# 📌 Sobre o Projeto

O **AgendeUniSales** é um sistema web de agendamento de reuniões acadêmicas desenvolvido com foco em organização, usabilidade e experiência visual semelhante ao AVA do UniSales.

O projeto foi criado com o objetivo de permitir que alunos realizem solicitações de reuniões com professores e coordenadores de maneira simples, moderna e intuitiva.

O sistema possui:

* Interface responsiva
* Layout inspirado no padrão visual do AVA
* Sistema de notificações
* Sidebar interativa
* Modal de detalhes
* Organização modular de arquivos
* Estrutura profissional de CSS e JavaScript

---

# 🎯 Objetivo do Sistema

O sistema foi desenvolvido para facilitar:

* Agendamento de reuniões acadêmicas
* Organização de solicitações
* Controle visual dos agendamentos
* Melhor experiência do aluno
* Centralização das reuniões acadêmicas
